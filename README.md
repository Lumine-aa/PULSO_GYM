# PULSO_GYM
GymControl - Sistema de Gestión Empresarial Digital para MIPYMES (Caso Gimnasio)

📌  Descripción del Proyecto
Este proyecto consiste en el diseño y desarrollo de un prototipo web modular de gestión
empresarial de bajo costo, accesible directamente desde el navegador de un computador o
dispositivo móvil sin necesidad de hardware especializado.
Se aborda como caso de demostración la gestión integral de un gimnasio en Cartagena de
Indias, permitiendo resolver los principales cuellos de botella operativos y financieros
mediante:
● Registro y gestión de socios/clientes.
● Control de ventas y suscripción de membresías.
● Historial y registro de pagos.
● Control manual de asistencia desde recepción.
● Visualización de reportes e indicadores clave (Dashboard).
